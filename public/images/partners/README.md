# Partner Logos

Place your partner organization logos here with the following names:

1. `akshaya-patra.webp` - Akshaya Patra logo (WEBP format)
2. `smile-foundation.webp` - Smile Foundation logo (WEBP format)
3. `unicef.svg` - UNICEF logo (SVG format)

All images will be automatically sized and adjusted to fit within a 128x128px container while maintaining aspect ratio.
